# PACMAN Game Center — сайт сети клубов (Актобе)

Сайт шести компьютерных клубов Pacman: клубы, залы, железо, прайс, акции и бронь через WhatsApp.

## Запуск

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # статическая сборка в dist/
npm test         # тесты текста брони и целостности данных
```

## Превью на GitHub Pages

Каждый пуш в `main` собирает сайт и публикует его по адресу
https://mumitrol16666-creator.github.io/packman/ (workflow `.github/workflows/preview.yml`, ветка `gh-pages`).
Превью закрыто от поисковиков метатегом `noindex`. Собрать такую же версию локально: `npm run build:preview`.

Боевая сборка (`npm run build`) рассчитана на корень домена `pacman.kz`. Другой домен или подпапка задаются
переменными `SITE_URL` и `SITE_BASE`. Все внутренние ссылки строятся через `url()` из `src/lib/url.js`.

## Объём первой версии

Информация о клубах, прайс, железо, акции и бронь через WhatsApp. Онлайн-загрузку залов и интеграцию
с клубной программой в первой версии не делаем. Дальше по плану: сервис приёма событий и Telegram-бот
с отчётами, админка для маркетологов, упаковка в Docker, раздел турниров.

## Где что менять

| Что | Файл |
| --- | --- |
| Клубы: адрес, WhatsApp, зоны, железо, цены | `src/data/branches.json` |
| Акции, удобства, правила, время пакетов | `src/data/site.json` |
| Фото клуба | `src/assets/photos/<slug>/` — подхватываются автоматически, первое по имени становится обложкой |
| Картинки для превью ссылок | `npm run og` пересобирает `public/og/` из обложек клубов |
| Текст сообщения в WhatsApp | `src/lib/booking.js` |
| Цвета и шрифты | `src/styles/global.css` |

У клуба без фотографий (сейчас Prime и City) вместо обложки рисуется заглушка с названием. Достаточно положить снимки в папку клуба.

## Бронь

Форма собирает сообщение и открывает `wa.me` нужного клуба. Сайт сам ничего не отправляет и не хранит имён и телефонов. В конце сообщения стоит код заявки (`#A7K2`), по которому администраторы могут сверять заявки с сайта.

## Аналитика

События кликов размечены атрибутами `data-track`. Отправка включается переменной `PUBLIC_TRACK_URL` в `.env` (см. `src/lib/track.js`); пока сервиса приёма нет, события никуда не уходят.

## Источники данных

Адреса, телефоны, железо и цены взяты из карточек клубов в 2ГИС (обновлены 08.09.2026) и сверены со сторис из брендбука. Расхождения, которые нужно подтвердить у клуба, записаны в поле `needsReview` в `branches.json`.
